# ICP Paper Draft

Build:

```bash
python ../scripts/make_icp_figures.py
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

The figure sources are generated by `scripts/make_icp_figures.py` to keep the
schematics reproducible and publication-style.

The multi-seed result tables are stored in `tables/` and are generated from
`experiments/icp/run_review_experiments.py`.

Raw CSV/JSON outputs used for the paper tables are stored in `results/`.
Reviewer-facing completion notes are in `REVIEW_FIX_CHECKLIST.md`.

Membership-function sensitivity is generated by
`experiments/icp/run_membership_ablation.sh` and
`experiments/icp/summarize_membership_ablation.py`.
